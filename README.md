# Family Quest 🏕️

一个给 Alex 和 Leo 使用的家庭学习与目标冒险小游戏。

## V1 已实现

- Alex / Leo 角色切换
- 长期目标成长路线
- 每日任务
- XP 经验值与自动升级
- 金币奖励
- 妈妈后台：新增任务、修改当前目标、手动奖励
- 浏览器本地保存数据（localStorage）
- 手机 / Mac 浏览器自适应界面

## 如何打开

这是纯 HTML/CSS/JavaScript 第一版，不需要安装依赖。

直接打开 `index.html` 即可运行。

如果要发布成在线网页，可以开启 GitHub Pages，或下一版迁移到 React / Next.js 并部署到 Vercel。
